# 🌸 はなまるExcel

> 毎日5分、おうちでスキルアップ — 花を育てながらExcel・IT資格を学べるゲーム

**🎮 [https://bonsai.github.io/hanamaru-excel/](https://bonsai.github.io/hanamaru-excel/)**

---

## 特徴

- 💴 **正解でお小遣いゲット** — 問題を解くたびに金钱が貯まる
- 🌷 **花を咲かせながら学習** — 正解するたびに花が咲き、お花屋さんが成長
- 🏡 **お部屋づくり** — 正解で家具が増え、理想のお部屋が完成
- ⏱️ **5分チャレンジ** — タイマー付きの集中モード
- ☕ **カフェ経営** — メニュー集めながら学習
- ✨ **バッジコレクション** — 18種類のバッジを解除
- 📅 **スタンプ帳** — 毎日の学習を記録
- 🧠 **難易度自動調整** — 間違えると簡単な問題、正しいと難しい問題

## 問題カテゴリ

| カテゴリ | 内容 |
|---------|------|
| Excel | SUM/IF/VLOOKUP関数、グラフ、ピボットテーブル |
| ITパスポート | CPU/RAM、クラウド、DX、サイバーセキュリティ |
| Word | 見出しスタイル、差し込み印刷 |
| PowerPoint | スライドショー、マスター |

## 技術構成

- **HTML1ファイル完結** — サーバー不要、ブラウザでそのまま動作
- **PWA対応** — スマホのホーム画面に追加可能
- **オフライン動作** — Service Workerでキャッシュ対応
- **localStorage保存** — 進行状況はブラウザに自動保存
- **SPA方式** — 画面切り替えで6つのセクションを切替

## 使い方

1. [GitHub Pages URL](https://bonsai.github.io/hanamaru-excel/) を開く
2. 名前を入力してスタート
3. 4択クイズに答える
4. 正解するとお金が貯まり、花が咲く
5. お金でお花や家具を購入
6. 毎日続けると昇格＆バッジ解除
